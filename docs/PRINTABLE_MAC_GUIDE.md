### Thumb Cluster Key Functions
**Left Thumb (from left to right):**
- BSPC: Extra backspace
- VOL-: Volume down
- VOL+: Volume up
- BSPC: Backspace
- SPACE: Spacebar
- **FN (hold)**: Access Function Layer

**Right Thumb (from left to right):**
- SPACE: Spacebar
- CMD: Command key (⌘)
- SHIFT: Right shift
- ENTER: Return key
- CTRL: Right control
- **FN2 (hold)**: Access System Layer

### Nav Cluster (Center)
The 5-way navigation switch in the center:
- **↑**: Up arrow
- **↓**: Down arrow
- **←**: Left arrow
- **→**: Right arrow

### Common Mac Shortcuts (Left Home Row)
Hold FN and press:
- **B**: Select All (⌘A)
- **Y**: Copy (⌘C)
- **O**: Paste (⌘V)
- **U**: Cut (⌘X)
- **'**: Undo (⌘Z)

### Window Snapping (Nav Cluster)
**Requires: Rectangle or Magnet app installed**

Hold FN and press nav cluster:
- **↑**: Maximize window (Ctrl+Opt+↑)
- **↓**: Restore window (Ctrl+Opt+↓)
- **←**: Snap window left half (Ctrl+Opt+←)
- **→**: Snap window right half (Ctrl+Opt+→)

**Setup Rectangle:**
1. Download from https://rectangleapp.com (free)
2. Open Rectangle preferences
3. Ensure shortcuts match:
   - Left Half: ⌃⌥←
   - Right Half: ⌃⌥→
   - Maximize: ⌃⌥↑
   - Restore: ⌃⌥↓

### Navigation & Special Keys
- **F1-F12**: Function keys
- **PG UP/DN**: Page up/down
- **HOME/END**: Line start/end
- **INS**: Insert key
- **LCLK**: Left mouse click (center thumb)
- **RGB controls**: Underglow lighting
- **WIN! (F12)**: Switch to Windows mode

### Bluetooth Profiles
Connect to up to 5 devices:
- **BT1-5**: Select Bluetooth profile 1-5
- **CLR**: Clear current profile
- **CLRAL**: Clear all profiles

### Output Control
- **USB**: Force USB connection
- **BLE**: Force Bluetooth connection

### System Commands
- **RESET**: Soft reset keyboard
- **BOOT**: Enter bootloader (for firmware updates)
- **OFF**: Deep sleep mode (press reset to wake)

## Common Tasks

### Daily Typing
- Type normally on base layer
- Use **FN + B/Y/O/U/'** for quick copy/paste operations
- Use **FN + arrows** to snap windows while working

### Window Management
1. **Maximize window**: Hold FN, press ↑
2. **Snap left**: Hold FN, press ←
3. **Snap right**: Hold FN, press →
4. **Restore**: Hold FN, press ↓

### Text Editing Shortcuts
- **Select All**: FN + B
- **Copy**: FN + Y
- **Cut**: FN + U
- **Paste**: FN + O
- **Undo**: FN + '

### Switching Bluetooth Devices
1. Hold FN2 (right thumb)
2. Press number key for profile (BT1-BT5)
3. Device should connect automatically

### Pairing New Device
1. Hold FN2
2. Press CLR to clear current profile
3. On your Mac: System Settings → Bluetooth
4. Select "Sofle" from available devices

### Switching to Windows Mode
1. Hold FN (left thumb)
2. Press F12 (bottom-right corner)
3. Keyboard switches to Windows layout
4. To return: Hold FN, press F12 again

## Troubleshooting

### Window snapping not working
- Install Rectangle app from rectangleapp.com
- Check Rectangle shortcuts match keyboard
- Try Magnet as alternative ($4.99 from Mac App Store)

### Bluetooth won't connect
- Hold FN2 + CLR to clear profile
- On Mac: Remove device from Bluetooth settings
- Re-pair from scratch

### Keys not responding
- Check battery level (both halves)
- Try soft reset: FN2 + RESET
- Reflash firmware if persistent

### One half not working
- Power cycle both halves
- Flash settings_reset.uf2 to both
- Reflash normal firmware

## Firmware Updates

1. Download latest firmware from GitHub Actions
2. Files needed:
   - `eyelash_sofle_left-nice_view-zmk.uf2`
   - `eyelash_sofle_right-nice_view-zmk.uf2`
3. Flash **RIGHT half first**:
   - Double-press reset button
   - Drag .uf2 file to NICENANO drive
   - Wait for disconnect
4. Flash **LEFT half**:
   - Same process with left .uf2 file
5. Power cycle both halves

## Quick Tips

- **Two spaces**: Left and right thumb both have space for comfort
- **Delete vs Backspace**: Top-right is DELETE, thumb is BACKSPACE
- **Volume**: Encoder knob controls volume (or VOL-/VOL+ keys)
- **Caps Lock**: Tap CAPS on left pinky
- **Command key**: Right thumb, easy for shortcuts
- **Mouse click**: Available on function layer center thumb
