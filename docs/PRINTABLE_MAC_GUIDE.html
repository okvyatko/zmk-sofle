Function Layer (Layer 1 – Hold FN)

Window snapping (requires Rectangle or Magnet):

  • FN + ↑ = Maximize (⌃⌥↑)
  • FN + ↓ = Restore (⌃⌥↓)
  • FN + ← = Snap Left (⌃⌥←)
  • FN + → = Snap Right (⌃⌥→)

Common shortcuts (left home row) while holding FN:

System Layer (Layer 2 – Hold FN2)

BluetoothBT1–BT5 select profile · CLR clear current · CLRAL clear all
OutputUSB/BLE force output mode
SystemRESET soft reset · BOOT bootloader · OFF deep sleep

Tip: Pair your Mac to the left (central) half only. The right half connects to the left automatically.

Mode Switching

  • To Windows mode: Hold FN → press bottom-right (F12 position)
  • Back to Mac: From Windows, hold FN → press bottom-right (F12 position)

Troubleshooting

  • Snapping doesn’t work: Install Rectangle and set shortcuts to ⌃⌥ + Arrows.
  • Halves not linked: Reflash right then left; if needed, flash settings_reset on both.
  • Bluetooth stuck: FN2 + CLR; then re-pair in macOS Bluetooth settings.
