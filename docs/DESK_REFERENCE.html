WINDOWS MODE LAYERS

🔴 Layer 3 - Windows Base

Same layout as Mac base, but:

  • CMD → WIN key
  • FN1 → FN4 (Windows functions)
  • All other keys identical

📋 Text Operations (Windows)

ActionKeys
Select AllFN4 + B (Ctrl+A)
CopyFN4 + Y (Ctrl+C)
PasteFN4 + O (Ctrl+V)
CutFN4 + U (Ctrl+X)
UndoFN4 + ' (Ctrl+Z)

🟠 Layer 4 - Windows Functions

Same as Mac functions, but:

  • Native Win10/11 snapping
  • Ctrl shortcuts (not Cmd)
  • F12 → Switch to Mac

🪟 Window Management (Windows)

ActionKeys
MaximizeFN4 + ↑ (Win+↑)
MinimizeFN4 + ↓ (Win+↓)
Left HalfFN4 + ← (Win+←)
Right HalfFN4 + → (Win+→)
EMERGENCY & TROUBLESHOOTING

🚨 Emergency Reset

ProblemSolution
Keys not workingFN2 + G (Soft Reset)
Need to reflashFN2 + J (Bootloader)
BT won't pairFN2 + B (Clear profile)
Complete resetFlash settings_reset.uf2

😴 Sleep Mode

Activate: Press G + A + Q together (2 sec)
Wake: Press reset button once

💡 Pro Tips

  • Two Space Keys: Use either thumb
  • Volume: Encoder knob or Vol keys
  • Delete vs Backspace: DEL = top right, BSPC = thumb
  • Mouse Click: Available on FN layers center thumb
  • RGB Effects: FN1 + G/X for on/off, J/K for effects

📚 Setup Notes

  • Mac Window Snapping: Native support (Globe+Ctrl+Arrows)
  • Windows Snapping: Works natively in Win10/11
  • Flash Order: Always RIGHT half first, then LEFT
  • 5 BT Profiles: Can connect to 5 different devices
