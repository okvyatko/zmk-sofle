## 🟢 **LAYER 1 - MAC FUNCTIONS** (Hold FN1)

```
┌─────┬─────┬─────┬─────┬─────┬─────┐             ┌─────┬─────┬─────┬─────┬─────┬─────┐
│  `  │ F1  │ F2  │ F3  │ F4  │ F5  │   🪟MAXIM   │ F6  │ F7  │ F8  │ F9  │ F10 │ DEL │
├─────┼─────┼─────┼─────┼─────┼─────┤   🪟RESTOR  ├─────┼─────┼─────┼─────┼─────┼─────┤
│     │⌘ A  │⌘ C  │⌘ V  │⌘ X  │⌘ Z  │             │PG UP│ END │  ↑  │HOME │  -  │  =  │
├─────┼─────┼─────┼─────┼─────┼─────┤   🪟SNAP ←  ├─────┼─────┼─────┼─────┼─────┼─────┤
│     │  ~  │🖱️LCK │🖱️MCK │🖱️RCK │🖱️MB4│             │PG DN│  ←  │  ↓  │  →  │  [  │  ]  │
├─────┼─────┼─────┼─────┼─────┼─────┤   🪟SNAP →  ├─────┼─────┼─────┼─────┼─────┼─────┤
│     │🌈OFF│🌈 ON │🌈EFF│🌈EFR│🌈SPI│             │🌈BRI│🌈BRD│ INS │ F11 │ F12 │🔴WIN│
└─────┴─────┼─────┼─────┼─────┼─────┤             ├─────┼─────┼─────┼─────┼─────┴─────┘
            │MUTE │     │     │ ▓▓▓ │             │🖱️LCK │     │     │     │
            └─────┴─────┴─────┴─────┘             └─────┴─────┴─────┴─────┘
```

**🪟 Window Snap:** ↑=Max, ↓=Restore, ←=Left, →=Right *(Requires Rectangle/Magnet)*  
**📋 Mac Shortcuts:** ⌘A=All, ⌘C=Copy, ⌘V=Paste, ⌘X=Cut, ⌘Z=Undo  
**🖱️ Mouse:** LCK=Left, MCK=Middle, RCK=Right, MB4=Back  
**🌈 RGB:** ON/OFF, EFF=Effects, BRI/BRD=Brightness  
**🔊 Encoder:** Scroll Up/Down

## ⚡ **QUICK ACTIONS**

### 🔄 **OS Switching**
- **Mac → Windows:** FN1 + F12
- **Windows → Mac:** FN4 + F12

### 📋 **Text Operations**
| Action | Mac | Windows |
|--------|-----|---------|
| Select All | FN1 + B | FN4 + B |
| Copy | FN1 + Y | FN4 + Y |
| Paste | FN1 + O | FN4 + O |
| Cut | FN1 + U | FN4 + U |
| Undo | FN1 + ' | FN4 + ' |

### 🪟 **Window Management**
| Action | Mac (FN1+) | Windows (FN4+) |
|--------|-------------|----------------|
| Maximize | ↑ | ↑ |
| Restore/Minimize | ↓ | ↓ |
| Snap Left Half | ← | ← |
| Snap Right Half | → | → |

### 📶 **Bluetooth (FN2)**
- **BT1-BT5:** Select profile (up to 5 devices)
- **CLR:** Clear current profile  
- **ALL:** Clear all profiles
- **USB/BLE:** Force connection type

### 😴 **Sleep Mode**
- **Activate:** Press G + A + Q together (hold 2 sec)
- **Wake:** Press reset button once

## 🚨 **Emergency Reset**
1. **Soft Reset:** FN2 + RST
2. **Bootloader:** FN2 + BTL (both halves)
3. **Settings Reset:** Flash settings_reset.uf2
4. **Hard Reset:** Disconnect battery 30sec

## 💡 **Pro Tips**
- **Two Space Keys:** Both thumbs have space - use either
- **Volume Control:** Encoder knob OR Vol-/Vol+ keys
- **Thumb Layers:** Left thumb = Functions, Right thumb = System
- **Mouse Clicks:** Available on center thumb in function layers
- **RGB Effects:** Cycle through 10+ lighting patterns
